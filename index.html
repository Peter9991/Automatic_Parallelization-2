03 · How it works
The analysis pipeline
01
📄
Parse Source
Reads C++ line-by-line, identifies for loop headers and extracts the loop variable, bounds, and step.
02
🔍
Dependency Analysis
Scans the loop body for arr[i±k] on the RHS of assignments — these are loop-carried dependencies that block parallelization.
03
⚙️
Pattern Detection
Detects reductions (+=, max), private scalar variables declared inside the body, and nested loop structures.
04
⚡
Pragma Injection
Builds the correct #pragma omp parallel for with reduction(), private(), and schedule() clauses.
04 · Detection rules
What gets detected
✓ Independent loop
Each iteration accesses only arr[i] with no cross-iteration data flow. Safe to distribute across threads.
// [AutoParallel] PARALLELIZED #pragma omp parallel for schedule(static) for (int i = 0; i < n; i++) b[i] = a[i] * 2 + 1;
✗ Loop-carried dependency
The pattern a[i-1] on the RHS means iteration i depends on i−1. Cannot parallelize.
// [AutoParallel] BLOCKED // loop-carried dep: a[i-1] for (int i = 1; i < n; i++) a[i] = a[i-1] + b[i];
Σ Reduction pattern
Detects +=, *=, and max/min accumulators. OpenMP handles thread-local copies automatically.
// [AutoParallel] PARALLELIZED + reduction #pragma omp parallel for \ reduction(+:sum) reduction(max:maxVal) for (int i = 0; i < n; i++) { sum += arr[i]; if (arr[i] > maxVal) maxVal = arr[i]; }
⊞ Nested loops
An inner for inside the body triggers schedule(dynamic) and a collapse(2) hint for further optimization.
// [AutoParallel] PARALLELIZED (nested) #pragma omp parallel for schedule(dynamic) /* consider: collapse(2) */ for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) C[i][j] = dot(A[i], B[j]);
